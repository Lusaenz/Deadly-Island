# Deadly Island

## Descripción del Proyecto

En un combate de sumo futurista, luchadores vibrantes y llenos de energía se enfrentan en una arena caótica donde solo el más fuerte permanecerá en pie. Cada empujón puede cambiar el curso de la batalla en segundos. ¡Domina la física, controla tu equilibrio y expulsa a tus oponentes antes de que te saquen a ti!

## Desarrollo

Este proyecto 3D comenzó como un ejercicio de la Unidad 4 de Unity Learn, pero fue expandido con elementos visuales más dinámicos y un diseño más pulido. Se reemplazaron los cubos estándar con **Party Monster Duo Polyart PBR** para un estilo más atractivo y se agregaron efectos sonoros de **SoundBits Free Sound FX Collection** para mejorar la inmersión en el juego.

### Características Principales

- **Motor de juego**: Unity
- **Lenguaje de programación**: C#
- **Física en tiempo real** con detección de colisiones y mecánicas de empuje dinámicas.
- **Diseño estilizado** con modelos 3D detallados y efectos visuales mejorados.
- **Efectos de sonido** envolventes para mayor inmersión.

## Retos

- Ajuste del balance en la jugabilidad para garantizar un combate justo pero caótico.
- Control preciso de fuerzas y empujones para una mecánica desafiante y divertida.

## Estado del Proyecto

**En desarrollo**. Se está refinando la jugabilidad y el diseño de niveles para una experiencia más fluida y emocionante.

## Instalación y Ejecución

1. Clona este repositorio en tu máquina local:
   ```sh
   git clone git@github.com:Lusaenz/Deadly-Island.git
   ```
2. Abre el proyecto en **Unity (versión recomendada: 2021.3 o superior)**.
3. Ejecuta la escena principal desde el editor de Unity.

## Controles del Juego

- Movimiento del personaje con **WASD** o flechas direccionales.
- Empujón con **barra espaciadora**.
